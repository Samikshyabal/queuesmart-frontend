QueueSmart

QueueSmart is a hospital queue management frontend designed to make patient waiting and token management easier.

The project provides separate interfaces for patients, hospital staff, and administrators. Patients can take a token and check their queue status, while the hospital can manage the queue and monitor patients.

Features--
Hospital-focused landing page
Patient login interface
Token generation and queue tracking
Live queue display
Counter management
Admin dashboard
Language switcher
Responsive UI
Reusable components for buttons, cards, badges, and navigation
Pages
Landing Page
Login Page
Token Page
Queue Display Page
Counter Page
Admin Dashboard

Tech Used--
React
Vite
Tailwind CSS
JavaScript
React Router
i18n for language support
Project Status

The frontend has been redesigned around the hospital queue management use case. The current version focuses mainly on the UI and frontend functionality. Backend integration and real-time queue updates can be added later.
